# Step 2: Create your Nova

**Time:** 2 to 3 minutes · **You'll need:** to be signed in to GitHub

You'll make your own private copy of Nova from the Nova template. Your copy is completely separate from the original: nobody else can see it, and nothing you put in it ever goes back to the template.

---

1. **Make sure you're signed in to GitHub** in your browser (you'll see your profile picture in the top-right corner of [github.com](https://github.com)).

2. **Open the Nova template:** **[github.com/CaptLocke/nova](https://github.com/CaptLocke/nova)**

3. **Click the green Use this template button** near the top right of the page.

   ![Screenshot: The Nova template page with the green "Use this template" button highlighted](images/nova-template-page.png)

4. **Click Create a new repository** in the small menu that opens.

   ![Screenshot: The menu open, "Create a new repository" highlighted](images/use-template-menu.png)

5. **Check the Owner.** It should show your GitHub username. If you belong to any organizations on GitHub, make sure your **personal** username is selected.

6. **Type a name in Repository name.** We suggest **`nova`**. Write the name down next to your username: you'll need both in step 4.

7. **Leave Description empty** (or write anything you like).

8. **Choose Private.** This is the most important choice in the whole setup.

   ![Screenshot: The form with name "nova" and **Private** selected and circled](images/create-repo-form.png)

   > ⚠️ **Make sure "Private" is selected, not "Public".** A public repository can be seen by anyone on the internet. Your Nova will hold information about your work, so it must be private. If you choose Public by mistake, see [Troubleshooting: my repository is public](troubleshooting.md#my-repository-is-public-by-mistake).

9. **Leave "Include all branches" unticked.**

10. **Click Create repository.** After a few seconds you'll see your new repository.

11. **Check for the word "Private"** in a small label next to the repository name at the top of the page.

    ![Screenshot: The new private repo, with the "Private" label next to its name circled](images/new-repo-created.png)

You now have your own Nova. You'll see a list of files and folders; you don't need to open or change any of them. Nova looks after them.

> **If it looks different:**
> - **No "Use this template" button?** Make sure you're signed in. If your browser window is narrow, the button may have moved; try making the window wider. You can also open this link directly, which takes you straight to step 5: [github.com/new?template_owner=CaptLocke&template_name=nova](https://github.com/new?template_owner=CaptLocke&template_name=nova). More help: [Troubleshooting](troubleshooting.md#i-cant-find-use-this-template).
> - **You see "Fork" but not "Use this template"?** Don't use Fork. Forks of a public repository are public. Use the direct link above instead.
> - **The page asks you to choose between "Public" and "Private" in a drop-down** rather than with round buttons: choose **Private**.

---

**Write down your Nova's address.** It's your username and the repository name joined with a slash, for example:

```
maya-chen/nova
```

You'll paste this in step 4.
